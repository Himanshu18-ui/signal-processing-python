# 📊 Signal Processing Using Python

## 📌 Overview

This repository contains implementations of fundamental digital signal processing (DSP) techniques using Python. The project focuses on frequency-domain analysis and digital filtering methods applied to simulated and noisy signals.

It demonstrates practical understanding of Fourier analysis, filter design, and frequency-domain comparison using scientific computing libraries.

---

## 🎯 Objective

To analyze signals in the frequency domain and implement digital filtering techniques to remove noise and study spectral characteristics before and after filtering.

---

## 🔬 Implemented Concepts

### 1️⃣ Fast Fourier Transform (FFT)
- Frequency spectrum analysis using Fast Fourier Transform.
- Visualization of magnitude spectrum.
- Identification of dominant frequency components.

### 2️⃣ Digital Filter Design
- Low-Pass Filter (LPF)
- High-Pass Filter (HPF)
- Band-Pass Butterworth Filter
- Implementation using SciPy signal processing tools.

### 3️⃣ Frequency Analysis Before & After Filtering
- Comparison of noisy signal spectrum.
- Evaluation of filtering effectiveness.
- Visualization of spectral improvements.

---

## 🛠 Tools & Libraries

- Python
- NumPy
- SciPy
- Matplotlib

## ⚙️ Project Structure
